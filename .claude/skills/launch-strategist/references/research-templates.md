# Research Templates

## 1of10 Search Recording Template

Use this format to record Ceiling/Floor results:

```
KEYWORD: [keyword]
DATE SEARCHED: [date]

CEILING (Top Performers):
1. Title: "[exact title]"
   Views: [X]M | Channel: [name] | Outlier Score: [X]x
   Description snippet: "[first 100 chars]"

2. Title: "[exact title]"
   Views: [X]M | Channel: [name] | Outlier Score: [X]x
   Description snippet: "[first 100 chars]"

FLOOR (Low Performers):
1. Title: "[exact title]"
   Views: [X]K | Channel: [name]

PATTERNS OBSERVED:
- [What ceiling titles have in common]
- [What floor titles lack]
```

## X Advanced Search Recording Template

```
SEARCH TERMS: [words used]
FILTERS: Last 12 months, 1000+ likes
DATE SEARCHED: [date]

HIGH PERFORMERS (5K+ likes):

1. @[handle] | [X]K likes | [X]K retweets
   "[Exact post text - first 280 chars]"
   
   Hook type: [controversial/curiosity/announcement/demo]
   Structure: [what comes first, second, third]
   CTA: [what they ask people to do]

2. @[handle] | [X]K likes | [X]K retweets
   "[Exact post text]"
   ...

PATTERNS OBSERVED:
- Hook patterns that repeat
- Common structures
- CTA styles that work
```

## Reddit Pain Point Recording Template

```
SUBREDDIT: r/[name]
SEARCH TERMS: [terms used]
DATE SEARCHED: [date]

HIGH-UPVOTE COMPLAINTS:

1. Thread: "[thread title]"
   Upvotes: [X] | Comments: [X]
   
   Key quote: "[exact user quote]"
   User context: [what they were trying to do]
   Emotional tone: [frustrated/desperate/resigned/angry]

2. Thread: "[thread title]"
   ...

LANGUAGE PATTERNS:
- Words they use to describe the problem
- Emotional phrases
- Specific numbers/timeframes they mention
```
